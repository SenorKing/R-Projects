# Final Research Report

This repository contains the analysis and report for the study examining whether higher daily social media usage is associated with students' mental health scores.

## Research Question

Is higher daily social media usage associated with students' mental health scores?

## Files

- [Final-Research-report.Rmd](Final-Research-report.Rmd) — R Markdown source for the full report
- [Final-Research-report.pdf](Final-Research-report.pdf) — compiled PDF version of the final report

## Summary

The analysis uses the "Students and Social Media" dataset to explore the relationship between:

- Independent variable: Avg_Daily_Usage_Hours
- Dependent variable: Mental_Health_Score

The report includes descriptive statistics, a scatterplot, and a Pearson correlation analysis. The final result shows a strong negative relationship: as average daily social media usage increases, mental health scores tend to decrease.
